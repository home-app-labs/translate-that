The first public version of Translate That.

- A translator in the menu bar: click the icon, or press ⌃⌘T in any app
- Text selected in the app you are in is picked up and translated straight away
- Google Translate out of the box, translating as you type
- Source language detected or chosen, and a button that swaps the two languages
- Copy the result, or insert it into the app you came from with one key
- Optional: Claude through Claude Code, if it is set up on your Mac. More natural translations and an Improve mode that fixes grammar, spelling and phrasing. Translate That uses the sign-in that program already has and never sees a password, token or key
- Experimental: ChatGPT through Codex, the same way. It was built from the Codex documentation and has not been tried with many setups yet. Please report what you find
- Settings: your own shortcut, launch at login, and a switch for each assistant
- No Dock icon, no account, no history. Nothing is stored except your settings

Translation needs a service: text you translate is sent to Google, or to Anthropic or OpenAI when you choose their assistant. Nothing is sent until there is text in the window.

**Install:** download `Translate-That.pkg` and open it. macOS blocks it the first time because the app is not signed with a paid Apple developer certificate: open System Settings → Privacy & Security and click "Open Anyway". Pictures of each step are on https://homeapplabs.com/install/

Works on macOS 14 or later, on Apple Silicon and Intel Macs.
